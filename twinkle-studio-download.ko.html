Twinkle Studio
English

진짜 칩에 불을 켜며 코딩을 배워보세요.

Twinkle Studio는 실제로 작동하는 초소형 마이크로컨트롤러, ATtiny85를 기반으로 만든 초보자 친화적인 코딩 앱입니다. 블록을 끌어다 놓거나, 파이썬 코드를 작성하거나, 원하는 동작을 평범한 말로 설명해보세요. 그런 다음 실제 하드웨어에 업로드하고 직접 작동하는 모습을 확인할 수 있습니다.

설치 방법

몇 분이면 설정 완료

사용하시는 운영체제를 선택하세요. Homebrew나 Xcode 등을 미리 설치할 필요가 전혀 없습니다 — 필요한 시점에 앱이 자동으로 컴파일러 도구를 설치합니다.

  1. 1

    다운로드 후 압축 풀기

    위에서 macOS용 .zip 파일을 다운로드한 다음 더블클릭하세요. 그러면 Twinkle Studio.app 파일이 생성됩니다.

  2. 2

    Applications 폴더로 이동 (선택 사항)

    앱을 Applications 폴더로 끌어다 놓거나, 편한 위치에 그대로 두고 더블클릭해서 열어도 됩니다.

  3. 3

    처음 실행하기

    macOS에서 "확인되지 않은 개발자"의 앱이라는 메시지가 뜰 수 있습니다 — 소규모 독립 개발 앱에서는 흔히 있는 일입니다.

    해결 방법: 앱을 마우스 오른쪽 버튼(또는 Control 키를 누른 채)으로 클릭하고 열기를 선택한 다음, 나타나는 대화상자에서 다시 한 번 열기를 클릭하세요. 이 과정은 처음 한 번만 하면 됩니다.
  4. 4

    컴파일러 자동 설치

    프로그램을 처음 업로드하려고 하면 Twinkle Studio가 AVR 컴파일러 도구를 자동으로 다운로드하고 설치해 줍니다 — 별도의 설치 과정이 필요 없습니다.

  5. 5

    USBasp를 연결하고 1강 시작하기

    USBasp 프로그래머를 연결하고, 1강에서 안내하는 대로 LED를 배선한 다음 '칩에 업로드'를 눌러보세요.

  1. 1

    zip 파일 다운로드

    위에서 Windows용 .zip 파일을 다운로드하세요. 이것은 설치 프로그램이 아니라 일반 압축 파일이며, 직접 앱을 열기 전까지는 아무것도 실행되지 않습니다.

  2. 2

    압축을 완전히 풀기

    다운로드한 파일을 마우스 오른쪽 버튼으로 클릭하고 압축 풀기를 선택하세요. 압축 파일 안에서 바로 앱을 실행하지 말고, 먼저 압축부터 풀어주세요.

  3. 3

    앱 실행하기

    압축을 푼 win-unpacked 폴더를 열고 Twinkle Studio.exe를 더블클릭하세요.

  4. 4

    보안 경고 화면 넘기기

    이 앱은 등록된 게시자의 것이 아니기 때문에 Windows에서 파란색 "Windows에서 PC를 보호했습니다" 화면이 나타날 수 있습니다.

    해결 방법: 추가 정보를 클릭한 다음 실행을 클릭하세요. 이 과정은 처음 한 번만 하면 됩니다.
  5. 5

    컴파일러 자동 설치

    프로그램을 처음 업로드하려고 하면 Twinkle Studio가 AVR 컴파일러 도구를 자동으로 다운로드하고 설치해 줍니다.

  6. 6

    USBasp 드라이버 설치하기

    Windows에는 USBasp 프로그래머용 드라이버가 기본으로 포함되어 있지 않아서, Zadig라는 무료 도구를 사용해 한 번만 드라이버를 설치해주어야 합니다.

    Zadig로 드라이버 설치하기

    컴퓨터당 한 번, 약 2분 정도 걸립니다. 먼저 USBasp를 연결하세요.

    1. 1
      Zadig 다운로드 및 실행

      zadig.akeo.ie에서 무료로 다운로드한 후 zadig-2.9.exe를 더블클릭하세요. Zadig는 유료 인증서가 없기 때문에 Windows에서 SmartScreen 경고가 뜰 수 있습니다 — 추가 정보 → 실행을 클릭하세요. 정상적인 현상입니다.

    2. 2
      모든 장치 표시하기

      메뉴 바에서 Options를 열고 List All Devices를 켜세요 — 그렇지 않으면 USBasp가 보통 숨겨져 있습니다.

    3. 3
      USBasp 선택하기

      상단의 드롭다운 메뉴를 클릭하고 USBasp라는 항목을 선택하세요. 이름 없는 장치가 여러 개 나타난다면, 프로그래머를 뽑았다 다시 꽂아보면서 어느 항목이 바뀌는지 확인해보세요.

    4. 4
      드라이버 설치하기

      오른쪽 상자 옆의 화살표를 눌러 libusb-win32가 표시될 때까지 변경한 다음 Install Driver를 클릭하세요. 몇 초 후 완료 메시지가 나타나면 Zadig를 닫아도 됩니다.

  7. 7

    USBasp를 연결하고 1강 시작하기

    드라이버 설치가 끝나면 Twinkle Studio를 다시 열고, 1강에서 안내하는 대로 LED를 배선한 다음 '칩에 업로드'를 눌러보세요.
